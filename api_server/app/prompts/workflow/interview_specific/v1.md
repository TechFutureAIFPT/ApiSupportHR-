Tạo bộ câu hỏi phỏng vấn riêng cho từng ứng viên bằng tiếng Việt.

Chỉ trả về JSON:
{
  "questionSets": [
    {
      "category": "string",
      "icon": "fa-solid fa-user-check",
      "color": "text-purple-400",
      "questions": ["string"]
    }
  ]
}

Bối cảnh tuyển dụng:
- Vị trí: [[job_position]]
- Địa điểm: [[location_requirement]]

Ứng viên:
- Tên: [[candidate_name]]
- Chức danh: [[candidate_job_title]]
- Ngành: [[candidate_industry]]
- Cấp độ: [[candidate_level]]
- Điểm: [[candidate_score]]
- Hạng: [[candidate_rank]]
- Điểm mạnh: [[candidate_strengths]]
- Điểm yếu: [[candidate_weaknesses]]
- Nhóm mạnh: [[strong_areas]]
- Nhóm yếu: [[weak_areas]]

Yêu cầu:
1. Tạo 4 đến 5 nhóm câu hỏi.
2. Mỗi nhóm có 4 đến 5 câu hỏi có mục tiêu rõ.
3. Câu hỏi phải kiểm chứng điểm mạnh và đào sâu điểm yếu.
4. Tránh câu chữ mẫu chung chung.
