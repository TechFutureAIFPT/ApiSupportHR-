Tạo bộ câu hỏi phỏng vấn so sánh bằng tiếng Việt để giúp HR chọn ứng viên phù hợp nhất.

Chỉ trả về JSON:
{
  "questionSets": [
    {
      "category": "string",
      "icon": "fa-solid fa-scale-balanced",
      "color": "text-cyan-400",
      "questions": ["string"]
    }
  ]
}

Bối cảnh tuyển dụng:
- Vị trí: [[job_position]]
- Địa điểm: [[location_requirement]]

Danh sách ứng viên:
[[candidate_profiles]]

Yêu cầu:
1. Tạo 4 đến 5 nhóm câu hỏi.
2. Mỗi nhóm có 4 đến 5 câu hỏi tập trung vào so sánh.
3. Câu hỏi cần giúp HR phân biệt năng lực kỹ thuật, mức độ làm chủ công việc, phối hợp nhóm và mức độ gắn bó dài hạn.
4. Viết tiếng Việt có dấu, ngắn gọn và có thể dùng ngay trong phỏng vấn.
